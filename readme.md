## Start the app

This project uses the Node.js version specified in `.nvmrc`. (v25.2.1)
If you are not using the specified version of node switch to it with for example  **nvm** or **nvm-windows**.

```bash
npm install
npm run build
npm run start
```

## Assumptions
- Assuming the app needs to be maintainable and loosely coupled, I designed it with a Layered Architecture and Dependency Injection, despite it being more verbose for a small app.
